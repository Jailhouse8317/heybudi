# 🤖 HeyBudi: The Democratized AI Framework for NYP Students

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Target Audience](https://img.shields.io/badge/Audience-NYP%20Students-blue)](https://www.nyp.edu.sg)

Welcome to **HeyBudi**, a 12-week Final Year Project (FYPJ) designed to bridge the gap between technical and non-technical students across Nanyang Polytechnic. 

HeyBudi provides a curated, zero-cost framework of practical AI workflows to help students automate administrative hassles, build high-quality presentation assets, optimize study schedules, and streamline everyday campus logistics.

---

## 🎯 Core Objectives

* **Democratized Access (Zero Cost):** Every workflow strictly leverages free tiers, open-source software, or existing academic student perks (such as GitHub Education and Adobe student credits).
* **Frictionless UX:** Zero programming required. If you can send a text message, you can leverage HeyBudi.
* **Workforce Readiness:** Elevating the everyday digital capabilities of students across all six academic schools (SIT, SEG, SDM, SBM, SHSS, SAS).

---

## 📱 The 6 Core AI Lifecycles

HeyBudi targets six specific everyday academic and personal pain points:

| # | Workflow / Persona | AI Tool | Core Solution |
|---|---|---|---|
| 1 | **Multi-Tab Project Synthesizer** | Microsoft Edge Copilot | Cross-references multiple active browser tabs (briefs, rubrics) into a single Markdown milestone checklist. |
| 2 | **Non-Designer Asset Creator** | Adobe Firefly | Uses text-based Generative Fill to create elite presentation slide backdrops via school-backed accounts. |
| 3 | **Local Asset Sharpener** | Upscayl | Executes 4x local image upscaling for web logos or blurry charts directly on a student's laptop without cloud configurations. |
| 4 | **Logic Prototype Assistant** | GitHub Copilot | Inline IDE code prediction and conversational hardware-debugging (Arduino C++/Python) securely sandboxed. |
| 5 | **Autonomous Topic Explorer** | Manus AI | Deploys an autonomous browser agent to execute multi-step research and compile structured presentation outlines. |
| 6 | **Campus & Social Logistics Lens** | Mobile Vision / OCR | Instantly translates handwritten menus, extracts text layouts, and interprets complex hardware via mobile-native interfaces. |

## 📁 Repository Navigation

* **`/prompts`**: Contains copy-and-paste prompt templates optimized for Edge Copilot, Firefly, and Manus AI.
* **`/guides`**: Comprehensive, text-based walkthroughs explaining setup instructions (e.g., configuring local Upscayl or verifying GitHub Student Developer packs).
